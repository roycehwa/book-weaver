# 可选后续设计：正文阅读排版模式（尚未实施）

## 目标

在内容已确认、附录可选择略过之后，提供“阅读版”导出：段落可以自然跨原页流动，不强制原页一对一复刻。不改译文语义、不重新翻译、不自动改变章节。

## 适用范围与默认值

- EPUB 原生段落和标题优先；不套用 PDF 断行拼接规则。
- 文字型 PDF、单栏正文、少量独立图片优先。
- 扫描页、文字嵌图、复杂多栏、密集表格保留现有路径并提示，不自动强行重排。
- 在导出前选择“标准版 / 阅读版”，默认仍为标准版。阅读版单独版本，不覆盖已确认译文与旧成品。

## 数据约束

- 保留原始段落 ID、源页范围、人工修正版本；阅读块可关联多个原段落。
- 只在同章节内合并：原页边界不强制换段；标题、列表项、引文、注释边界不能跨越。
- 高把握的跨页续段和断词修复提供前后差异；不确定项保留原样，可人工合并或拆分。
- 图片作为独立图块，固定长宽比；图注跟随图片，不把文字图片误当可编辑正文。
- 不依靠删除图片或降低图片质量实现重排和缩小体积。

## 验证与人工入口

1. 每章提供重排前后预览、原文定位、撤销本章排版。
2. 输出前校验段落去向与顺序：不得漏字、重复、跨章、丢图；排版失败保留上次成品。
3. EPUB 检查窄屏/宽屏与可调整字体；PDF 检查分页、孤行、标题后段落和图注。
4. 用下一本真实文档验证章节开头、中段、结尾以及全部重排警告。重复性问题回到算法，不把逐段修复当作验收。

该功能不属于 2026-09-20 完成的 Phase A 流程开发包，也不作为当前真实书验收的通过条件。若以后启动，应作为独立版本开发和验收，不能混入对单本测试书的局部修补。
