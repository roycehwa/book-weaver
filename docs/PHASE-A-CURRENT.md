# Phase A：唯一续接摘要

更新：2026-09-20。用途：新开发对话的唯一规范入口。本文件只记录当前新流程、当前验证和待完成事项。

## 1. 目标与边界

将 BookWeaver 做成个人使用、可人工干预、可恢复、能可靠导出的书籍翻译应用。首发支持 EPUB 和文字型 PDF；扫描件及复杂多栏超出首发质量承诺。

- 只做 Phase A：解析、术语、章节、翻译、审阅、导出。不做知识拆分、多用户或完整排版编辑器。
- 先通过本机真实书籍质量与故障恢复验收，再考虑腾讯云。目标不是修好某一本书，而是修好通用算法。
- 原则上每百页必须手工修正的问题不超过 5 处；同类问题反复出现必须修算法。警告数量不等于人工修正数量。
- 零星内容判断允许人工干预；网络暂态故障与常规恢复不应反复把流程推给用户。不得无限重试、吞错或用原文冒充成功译文。

## 2. 不可绕过的工作流

格式解析 → 逻辑文档重建 → 用户确认重建后的原文、章节和内容策略 → 从确认范围提取并定稿术语 → 冻结输入 → 传输分块 → 翻译 → 异常审阅 → 导出。

- 术语、章节由用户确认，助手不能自动代签。术语数量由内容质量决定，不追求固定配额。
- 后端统一执行版本及启动检查；运行时冻结输入。上游修改使受影响结果过期，保护人工修订与批准版本。
- 原文件不变；原文修正可撤销。重复提交幂等，旧页面保存不能覆盖新版本。
- 可局部重译，重译要求允许为空；无关章节尽量复用，人工批准内容不被重试覆盖。
- 必须阻断：归属缺失、任务未完成、必需图片缺失、过期译文、生成失败。
- 疑似断词、术语差异、可能未译等可修正或注明理由接受。“保留原文/略过”是明确记录的用户决定，不计为翻译成功。
- 导出先临时生成并验证，再发布；失败不覆盖旧成品。图片不静默删减或降清晰度，异常体积要可解释。

## 3. 当前新基线

只有当前新流程代码、当前自动化测试以及由当前流程创建的完整验收任务可以证明能力。

- PDF 与 EPUB 都必须先归一为统一的逻辑阅读单元，再向用户展示实际待翻译文档并确认。PDF 依据节点、页码和几何 provenance 修复跨页结构；EPUB 依据 package、spine、navigation、XHTML DOM 和链接关系归一结构。EPUB 不套 PDF 断行规则，但也不把原始 XHTML 文件边界直接当成章节或翻译单元。
- 封面使用明确资源，不把出版社标志或第一张普通图片充当封面。
- 可解析目录/表格优先文字；空表格内嵌文字节点也要读取，不能直接转图。
- 简化模式默认关闭；识别后部 Notes、Bibliography、Glossary、Index 等候选，由用户确认正常处理、保留原文或略过。没有自动候选也允许手动指定。
- 章节插入使用明确标题与页范围，更新相邻范围；左栏保留页码输入，不显示内部文件链接。
- 用户已确认正文的翻译策略优先于自动页面分类，避免正文误判成参考文献后整章跳过。
- 同页下一章标题唯一匹配时按标题位置拆分，保留页内范围并检查遗漏/重叠；不确定时不猜。排除后章也不能丢弃同页前章结尾。
- 导出检查整章被错误跳过翻译的情况。这不是完整语义质量证明。
- 可选的“阅读版”全文重排仍是独立后续功能，见 REFLOW-DESIGN-2026-09-18.md；它不属于本轮既定流程开发，也不能当成已实现能力。

- 流程级方案见 `PHASE-A-PIPELINE-REDESIGN-2026-09-19.md`。流程主干已改造：新增 `bookweaver_reading_units_v1` 及 `reading-units.json`，确认区可查看重建连续正文；新任务 intake 后先等待原文/章节/内容策略确认，确认后才从 canonical book 的可翻译范围提取术语；Notes/Bibliography/Glossary 建议保留原文，Index 建议略过，确认时动作固化为 translate/preserve/exclude；确认后的 reading units 冻结为 `translation_authority: true`，chapter segments 和实际运输分块由它生成，产物保存 reading-units 指纹和 unit IDs。
- PDF 已保留 Docling 节点与字符范围；同一源节点跨相邻页时，确定性恢复源分隔符并消除有证据的页末断词。不同节点只有在相邻页、页边位置、栏位、缩进、字体/样式、语法和中间结构均提供高把握证据时才续接；标题、列表、表格、图片、题注等结构断点会阻断。对应 reading unit 保存两侧 span provenance。
- PDF 页脚清理不再按短文本长度直接删除内容：重复页脚、页码、出版信息等继续作为版面噪声处理，具有正文语法的唯一页底文本进入阅读流并接受续接判断。同栏且左边界一致的右侧参差正文可以通过高把握续接，真实跨栏、缩进、标题和结构障碍仍会阻断。
- PDF 封面现在只有一个规范资源章节：第一页渲染封面存在时，同页的 Cover/Cover Page 目录项不会再生成第二个逻辑章节；第一页可读文字仍保留在该资源中，后续正文页与章节所有权不受影响。EPUB 封面逻辑未改动。
- EPUB 已为标准语义块记录资源路径、DOM 路径、元素内字符范围、元素 ID 和链接目标。相邻 XHTML 资源只有在共享明确导航关系、弱延续资源或跨资源同段落等正向证据成立时才归入同一逻辑章节；真实导航、强标题、内容策略转换和结构障碍会阻断。同段落续接保留两侧独立 DOM provenance、锚点和链接目标，不拼接原始 XHTML。
- PDF 与 EPUB 共用 `bookweaver_continuation_decisions_v1` 决策台账并生成 `continuation-decisions.json`。被评估边界记录接受、拒绝或不确定状态、证据、原因和稳定指纹；接受的内部续接进入 reading unit 元数据。边界、文字或链接目标变化会改变 reading-units 指纹并使相关运输输入失效，完全相同输入保持稳定。
- 翻译后已经拆成确定性中文 Markdown 清洁和受约束模型润色两个步骤。源文、原始译文和润色结果分别生成质量报告及输入签名；过期产物、漏译/原文冒充、受保护术语/数字/引用变化、清洁或润色未决项会在进入下一阶段或导出前阻断。
- 章节源标题与译文显示标题已经分离：源标题继续用于 provenance 和审阅对齐；有章节标题单元证据时，译出的标题成为正文唯一一级标题和 EPUB 导航标题，不再在中文标题上方重复插入英文标题。用户选择翻译主目录时，系统不再把源目录的点线和页码送入模型，而是在翻译及审阅完成后按最终译文章节名重建目录；选择保留原文或略过时仍遵守用户决定。
- 人工审阅与导出质量门现在读取同一份有效状态：只有明确绑定到段落的漏译、缺失译文、缺失内容、疑似不完整或失败占位问题，且对应段落已批准或解决时，才可由人工裁决解除；来源、结构、链接、数字、受保护内容、过期签名以及缺失/篡改质量工件继续阻断。人工裁决不回写质量发现；规则升级时通过显式复算原子重建整套带签名报告。界面在仍有阻断时不再提示“可以直接导出”，导出按钮也不会发起必然失败的请求。合成整书审阅任务已验证段落阻断经人工补译后能够生成版本化译文。
- 原始译文质量检查现在分别校验冻结的 `translation-input.md` 签名和与 `translated.raw.md` 同形的完整交付源稿，不再把运输视图中的跳过注释、二级标题和省略章节同完整交付稿直接比较。内部 HTML 注释、声明、中文标点后的 URL 和可翻译图片替代文字不会造成结构误报；真实外链替换、链接目标丢失和语义 HTML 标签变化仍阻断。规则升级后的既有任务可从审阅页显式“重新校验现有译文”，只重建派生质量报告，不重新翻译或改写人工审阅决定。
- Notes/Endnotes 依赖只依据 EPUB DOM/内部链接及统一 reading-unit provenance 判定。用户选择略过被正文引用的注释时，界面建议改为“保留原文”，仍允许用户明确确认略过；后端只接受当前分析生成的依赖编号，并在重建预览成功后原子记录决定。
- 原文修正台与续接决策台账已对齐：已接受的续接显示为“已由续接决策核对”且不再重复列为待处理；不确定或因结构证据拒绝的真实候选进入确认页顶部质量摘要，不能再与“未发现问题”同时出现。
- 章节确认同时校验源文版本与任务版本，旧窗口不能覆盖较新的章节方案。普通 EPUB/PDF 输出先写同目录临时文件，完整生成后才替换正式成品。导出 worker 继承跨进程独占锁；重复提交不会派发第二个 worker，后端重启后可恢复无锁的 `exporting` 任务，失败任务允许安全重试。

- 用户界面保持四个阶段：导入；查看重建结果并确认；确认术语；审阅与导出。PDF 与 EPUB 的格式适配、质量检查和恢复状态均留在后台，不增加用户执行次数。

故障恢复自动验收矩阵：

| 场景 | 当前自动证据 |
| --- | --- |
| 断网、超时、模型暂态失败 | 有界重试、失败分类、暂停/恢复与缓存保留测试 |
| 后端重启 | 翻译/导出子进程继承文件锁；停滞翻译与导出由监督器接管 |
| 重复提交 | 重复上传显式确认；重复导出返回当前任务且不派发第二 worker |

| 边界变化 | continuation/reading-unit 指纹变化使旧运输输入和下游产物失效 |
| 导出失败 | EPUB/PDF 临时生成；注入失败时旧成品保留，清除临时文件；失败后可重试完成 |
| 缓存续跑 | 未变化内容按内容指纹复用；暂停和网络恢复不删除有效缓存 |
| 人工修改 | 草稿、批准译文和未受影响决定在刷新、重试和局部变化后保留 |

## 6. 接下来的顺序

1. 用户在新建整书任务中确认重建文档、章节和内容策略；随后完成术语确认、翻译、异常审阅及导出，验证确认后的全部质量门和恢复路径。
